How to export your Google Maps Timeline

Android: Settings → Location → Location services → Timeline → Export Timeline data. Save Timeline.json and import it here.

iPhone: Google Maps → your profile → Settings → Personal content → Export Timeline data.

Older history: takeout.google.com → Location History (Timeline). Unzip and import Records.json or the files in Semantic Location History.

Photos say "no GPS"?

Phones sometimes strip location when sharing photos with a web page. On Android, pick photos via Browse / Files rather than the Photos picker. On iPhone, tap Options in the picker and turn on Location, or import a Google Photos Takeout folder (its JSON files carry the location).

INSTALL AS APP
On Android: open this file in Chrome, tap the menu (⋮) and select Add to Home Screen. It will install as a full-screen app.

On iOS Safari: tap the Share button then Add to Home Screen.
STORAGE INFO
